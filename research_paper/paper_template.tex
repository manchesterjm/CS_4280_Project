\begin{abstract}
The detection of exoplanetary transits in stellar light curve data remains challenging due to noise, class imbalance, and stellar variability. We present a novel deep learning approach combining Bidirectional Long Short-Term Memory (BiLSTM) networks with K-means clustering to classify 2048-point time-series windows. Our method integrates physically-motivated features from Box Least Squares (BLS) periodograms to stratify windows into 5 clusters, enabling the model to learn specialized patterns for different stellar regimes. Trained on 655 windows (150 positive, 505 negative) from NASA's TESS mission, our model achieves an AUC of 0.6947, representing a 3\% improvement over baseline BiLSTM and 11.5\% improvement over classical machine learning. We validate our approach on real TESS data, successfully identifying TIC 307210830 (L 98-59 system with 4 confirmed planets) with mean probability 0.5959. Our cluster-enhanced architecture demonstrates the value of integrating domain knowledge with sequence modeling for astronomical time-series classification.
\end{abstract}

\section{Introduction}

The search for exoplanets has fundamentally transformed our understanding of planetary systems and the prevalence of potentially habitable worlds. NASA's Transiting Exoplanet Survey Satellite (TESS) monitors hundreds of thousands of stars, producing vast quantities of light curve data requiring automated analysis. The transit method detects planets by observing periodic dips in stellar brightness, but distinguishing genuine planetary transits from stellar variability, instrumental noise, and astrophysical false positives remains challenging.

Traditional transit detection algorithms, such as Box Least Squares (BLS), rely on mathematical models of idealized transit shapes. While effective for high signal-to-noise ratio (SNR) cases, these methods struggle with noisy data and require careful parameter tuning. Recent machine learning approaches have shown promise, but most treat time-series classification as a black-box problem without leveraging domain knowledge.

\textbf{Our Contribution:} We propose a cluster-enhanced BiLSTM architecture that:
\begin{itemize}
\item Integrates BLS-derived features (period, depth, duration, SNR) via K-means clustering
\item Learns cluster-specific representations through learnable embeddings
\item Processes bidirectional temporal context to identify transit morphology
\item Achieves AUC 0.6947 on validation data and successfully detects known exoplanets in real TESS observations
\end{itemize}

\section{Related Work}

\textbf{Classical Methods:} BLS and its variants have been the workhorses of transit detection for over two decades. However, these methods require clean, preprocessed data and struggle with stellar activity that mimics transit signals.

\textbf{Machine Learning:} Random Forests, Support Vector Machines, and other classical ML approaches have been applied to engineered features. Our experiments show these achieve AUC $\sim$0.53-0.58, limited by their inability to capture temporal dependencies.

\textbf{Deep Learning:} Convolutional Neural Networks (CNNs) have been applied to light curve classification, achieving strong performance on Kepler data. LSTM and GRU networks can model temporal sequences but often ignore physically-motivated features. Our work combines the strengths of both approaches.

\section{Methodology}

\subsection{Data Collection and Preprocessing}

Our dataset comprises:
\begin{itemize}
\item 100 confirmed exoplanet host stars from TESS/Kepler archives
\item 106 light curves including flares, noise, and non-planetary variability
\item 655 total windows (150 positive, 505 negative, 23\% positive class)
\end{itemize}

Each raw light curve undergoes:
\begin{enumerate}
\item \textbf{Robust detrending} to remove stellar variability
\item \textbf{Median normalization} (flux $\rightarrow$ median = 1.0)
\item \textbf{Z-score standardization} (zero mean, unit variance)
\item \textbf{Quality filtering} to remove bad cadences
\end{enumerate}

\subsection{Window Extraction Strategy}

We employ phase-folding based on BLS-detected periods:

\textbf{Positive windows} (3 per light curve):
\begin{itemize}
\item 1 centered at transit phase $\phi = 0.0$
\item 2 with small jitter ($\pm$5\% phase) for augmentation
\end{itemize}

\textbf{Negative windows} (5 per positive):
\begin{itemize}
\item Extracted from phases far from transits ($|\phi - 0.5| > 0.18$)
\item Ensures negatives contain no transit signals
\end{itemize}

Each window contains 2048 consecutive flux measurements, selected to capture full transit events while maintaining computational efficiency.

\subsection{Feature Extraction via Box Least Squares}

For each light curve, we compute BLS periodograms to extract:
\begin{itemize}
\item \textbf{Period (P)}: Orbital period in days
\item \textbf{Depth ($\delta$)}: Fractional brightness decrease
\item \textbf{Duration (T)}: Transit length in days
\item \textbf{BLS Power (SNR)}: Signal-to-noise ratio
\end{itemize}

These features capture the physical characteristics of planetary transits and enable meaningful clustering.

\subsection{K-means Clustering}

We apply K-means clustering ($k=5$) to standardized feature vectors $[P, \delta, T, \text{SNR}]$. The resulting clusters naturally stratify windows by:
\begin{itemize}
\item Hot Jupiters (short period, deep transits)
\item Temperate planets (long period, shallow transits)
\item High vs. low SNR detections
\item Noise-dominated windows
\end{itemize}

\subsection{BiLSTM Architecture}

Our model (Fig.~\ref{fig:architecture}) processes windows through:

\begin{enumerate}
\item \textbf{Cluster Embedding Layer}: Maps cluster ID (0-4) to 32-dimensional embedding
\item \textbf{BiLSTM Layers} ($\times$3): 256 hidden units per direction, layer normalization, dropout (0.4)
\item \textbf{Concatenation}: $[\text{LSTM}_{\text{out}}, \text{Cluster}_{\text{emb}}]$ (512 + 32 = 544 dim)
\item \textbf{Fully-Connected Layers}:
  \begin{itemize}
  \item FC1: $544 \rightarrow 256$ + BatchNorm + ReLU + Dropout
  \item FC2: $256 \rightarrow 128$ + BatchNorm + ReLU + Dropout
  \item FC3: $128 \rightarrow 1$ + Sigmoid
  \end{itemize}
\end{enumerate}

\textbf{Total parameters}: $\sim$2.1M

\subsection{Training Procedure}

\textbf{Loss Function}: Weighted Binary Cross-Entropy
\begin{equation}
\mathcal{L} = -\left[w_1 \cdot y \cdot \log(\hat{y}) + w_0 \cdot (1-y) \cdot \log(1-\hat{y})\right]
\end{equation}
where $w_1 = 3.367$ (positive weight $= 505/150$), $w_0 = 1.0$.

\textbf{Optimization}:
\begin{itemize}
\item Optimizer: AdamW (learning rate $= 10^{-4}$)
\item Scheduler: Cosine annealing over 80 epochs
\item Gradient clipping: max norm = 1.0
\item Mixed precision: FP16 (1.6$\times$ speedup)
\end{itemize}

\textbf{Data Split}: 85\% training (557 windows), 15\% validation (98 windows), stratified by class.

\textbf{Early Stopping}: Patience of 15 epochs on validation AUC.

\section{Discussion}

\subsection{Strengths}

\textbf{Domain Integration}: By clustering on BLS features, our model leverages astrophysical domain knowledge while retaining the flexibility of deep learning.

\textbf{Real-World Validation}: Successful identification of TIC 307210830 demonstrates practical utility despite moderate AUC.

\textbf{Efficiency}: Mixed-precision training achieves 1.6$\times$ speedup, enabling rapid iteration on limited hardware.

\subsection{Limitations}

\textbf{Small Dataset}: 655 windows is limited for deep learning. Modern exoplanet datasets (e.g., full TESS archive) contain millions of cadences.

\textbf{Performance Gap}: AUC 0.69 is below production thresholds ($\sim$0.85) for reliable automated detection.

\textbf{Low Recall}: Conservative filtering yields 10\% recall, missing many true planets. Threshold tuning could improve this metric.

\subsection{Future Work}

\textbf{Dataset Expansion}: Incorporate additional TESS sectors and Kepler data.

\textbf{Attention Mechanisms}: Identify which cadences are most informative for classification.

\textbf{Ensemble Methods}: Combine multiple models for robust predictions.

\textbf{Multi-Task Learning}: Jointly predict transit parameters (period, depth) alongside classification.

\section{Conclusion}

We present a cluster-enhanced BiLSTM architecture for exoplanet transit detection that achieves AUC 0.6947, outperforming both classical machine learning and baseline deep learning approaches. By integrating K-means clustering on physically-motivated BLS features, our model learns specialized decision boundaries for different stellar regimes. Validation on real TESS data demonstrates practical utility, with successful identification of confirmed exoplanet host TIC 307210830. While performance improvements are needed for production deployment, our work demonstrates the value of combining domain knowledge with deep sequence modeling for astronomical time-series classification.
